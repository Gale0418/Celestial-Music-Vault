# CMV 2.0 approved composition set

These three images are the comp-led north stars for the first native surface:

- `cmv-macos-celestial.png` — three-column Celestial Cloud Atlas.
- `cmv-ipad-landscape-celestial.png` — touch-first sky archive with a dismissible queue.
- `cmv-ipad-portrait-celestial.png` — a hand-held music world with a starlight playback route.

The earlier `*-crimson.png` images are rejected exploration retained only as design history; they are not implementation authority.

## Direction contract

- **World:** a Celestial Cloud Atlas where a private music library becomes a sky of luminous album-worlds.
- **First viewport:** the active album is a cloud portal; nearby records orbit as small worlds; a precise list floats on an atmospheric plane; queue entries form a trail through the sky.
- **Visitor path:** source constellation → active cloud-world → selected track → starlight playback route → queued destination.
- **Signature interaction:** a restrained multicolor trail links the selected row, active album, scrubber, and next queue world.
- **Cross-surface reach:** Mac reveals the complete sky atlas; iPad landscape makes it touch-explorable; portrait lets one music world fill the user's hands. Four themes change celestial weather, never topology.
- **Risk:** atmospheric layers may reduce contrast or performance. Place semantic surfaces beneath text, cap particle count, cache Canvas drawings, provide static Reduce Motion states, and preserve plain List alternatives.

The generated sky and album imagery is reference material only. Production artwork comes from the user's metadata or deterministic SwiftUI/Canvas placeholders.
