# INC-001：Mission Center 版本驗證錯置

- 狀態: 已解決
- 摘要: 首次現代化執行了 0.2.1 腳本，雖 Doctor OK，仍不符合使用者指定的 Mission Center 0.3.1。
- 影響: 缺少 0.3.1 的 bounded Resume packet、`working-set.md`、`critical-lessons.md` 與新版 execution checkpoint 驗證。
- 症狀: 實際腳本路徑含 `0.2.1+codex...`，而已安裝插件 manifest 為 `0.3.1+codex.9ed1bfeca60445639f45a35d424aa16e`。
- 重現: 比對腳本絕對路徑與已安裝 `.codex-plugin/plugin.json` 的 `version`。
- 根因: 執行前未先解析目前已安裝版本，直接使用舊快取路徑。
- 排除方案: 不以 0.2.1 Doctor 結果當成 0.3.1 證據；不手動偽造新版 snapshot。
- 最終修正: 重開 MC-E1，改用 0.3.1 插件目錄的腳本；以 Python 3.12 執行 snapshot，以避開系統 Python 3.9 不支援 `Path.write_text(newline=...)` 的相容性問題。
- 驗證證據: plugin manifest 基礎版 0.3.1；personal/plugin SKILL.md SHA-256 相同；Resume `schemaVersion=1.1`、`sourceFresh=true`；Doctor OK。
- 關聯: MC-M2、MC-E1；`decisions.md` 2026-08-14 版本決策。
